# 🧠 TCS NQT Passage Recall Trainer

Ek minimalistic, exam-jaisa practice tool for TCS NQT's naya **Verbal Ability — Passage Recall** section. Zero hocus-pocus, sirf timer, passage, aur tumhara dimaag. 💪

## 🎯 Kya karta hai ye?

TCS NQT ke naye format mein tumhe ek passage **30 seconds** ke liye dikhaya jaata hai, phir wo hide ho jaata hai aur tumhe **90 seconds** mein apne words mein rewrite karna padta hai. Ye app exactly wahi environment simulate karta hai — asli exam se pehle full practice.

### Flow:
1. **Read (30s)** — Passage padho, memorize karne ki koshish karo (copy-paste disabled, bilkul real exam jaisa)
2. **Write (90s)** — Passage hide ho jaata hai, apne words mein rewrite karo
3. **Instant Feedback** — Kitne exact phrases copy hue, key ideas kitni retain hui, word count kaisa raha
4. **4 Passages/Session** — 40-passage bank se random 4 uthaye jaate hain har baar

## ✨ Features

- ⏱️ **Real exam timing** — 30s read + 90s write, bilkul TCS ke format jaisa
- 🚫 **Copy-paste block** — na passage copy hoga, na textarea mein paste — genuine recall force hota hai
- 📊 **Smart feedback engine** — 4-word exact-match copy detection, key-idea coverage %, word count comparison
- 🎲 **40 diverse passages** — tech, environment, AI, healthcare, education, fintech aur bahut kuch — kaafi variety ki repeats jaldi nahi hongi
- 📱 **Zero setup** — single HTML file, koi installation nahi, bas browser mein kholo aur start

## ⚠️ Ek honest disclaimer

Feedback yahan **heuristic-based** hai (word overlap, phrase matching) — ye asli TCS AI grading engine nahi hai. Isko ek practice compass samjho, final scorecard nahi. Grammar aur sentence structure apna khud check karo.
